The rule that denied it

Policy is versioned with the service.

Gate 4 evaluates every layer against this rule. It denies anything without a provenance statement from a builder on the trusted list — there is no severity threshold to tune, because an untraceable layer is either present or it is not.

# policy/supply-chain/provenance.rego
package northwind.gates.signing

deny contains msg if {
    layer := input.image.layers[_]
    not layer.attestations.slsa_provenance
    msg := sprintf("layer %v has no SLSA provenance", [layer.digest])
}

deny contains msg if {
    builder := input.image.attestations.slsa_provenance.builder.id
    not trusted_builders[builder]
    msg := sprintf("builder %v is not on the trusted list", [builder])
}

Evaluated by conftest 0.56 against the image manifest. Waiving this rule needs two approvals from the platform security group.
